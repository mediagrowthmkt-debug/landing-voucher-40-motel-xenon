# 🎁 Landing Page Voucher R$40 - Motel Xenon

## 📋 Descrição

Landing page minimalista e sem rolagem (single-hero) focada em conversão direta para WhatsApp, oferecendo um voucher de R$40 para consumo no Motel Xenon Criciúma.

## 🎯 Objetivo

Converter tráfego de busca (palavras-chave: "Motel Criciúma", "Motel perto de mim") diretamente para reservas via WhatsApp.

## ✨ Características

### Design
- ✅ **Layout Single-Hero**: Sem rolagem, toda informação visível na primeira tela
- ✅ **Minimalista**: Design limpo focado na oferta e CTA
- ✅ **Responsivo**: Otimizado para mobile e desktop
- ✅ **Carregamento Rápido**: Apenas 3 arquivos (HTML, CSS, JS)

### Elementos
- 🏷️ Badge animado com voucher destacado
- 🎬 Vídeo de fundo da suíte (opcional)
- ✨ Ícones de features principais
- 📱 Botão WhatsApp proeminente com mensagem pré-preenchida
- 🏆 Elementos de confiança e localização

### Tecnologia
- HTML5 semântico
- CSS3 com animações suaves
- JavaScript vanilla (sem dependências)
- Google Analytics e Microsoft Clarity integrados
